# Sberbank Russian Housing Market — EDA

Поверхностный разведочный анализ данных соревнования Kaggle
[Sberbank Russian Housing Market](https://www.kaggle.com/competitions/sberbank-russian-housing-market).

**Задача:** предсказать цену квартиры в Москве (`price_doc`).

## Файлы
- `eda.ipynb` — ноутбук с анализом по шагам
- `data/` — `train.csv`, `macro.csv`, `data_dictionary.txt` (CSV не в git — скачать с Kaggle)

## Запуск
```bash
pip install pandas matplotlib seaborn jupyter
jupyter notebook eda.ipynb
```
